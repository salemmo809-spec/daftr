المزامنة بين الأجهزة

طريقة الإعداد (مرة واحدة)
  1. ادخل console.firebase.google.com بحساب Google وأنشئ مشروعاً جديداً (يمكنك إيقاف Analytics).
  2. من القائمة: Build ثم Firestore Database ثم Create database (أي منطقة).
  3. افتح تبويب Rules والصق القواعد التالية ثم Publish:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /notebooks/{id} {
      allow get: if true;
      allow create, update: if request.resource.data.keys().hasOnly(['t','u','n']);
    }
  }
}
  1. من Project settings ثم General ثم Your apps: أضف تطبيق ويب (</>) وانسخ apiKey وprojectId.
  2. الصقهما هنا، واضغط «توليد» لكود المزامنة، ثم «حفظ وتفعيل». انسخ «كود الربط» والصقه على الجهاز الثاني.
